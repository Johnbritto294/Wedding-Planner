# STACKLY - Luxury Wedding Planning Hero Landing Page

A pixel-perfect, responsive reproduction of the STACKLY wedding planning hero section and navigation bar built directly from the Figma design specifications.

## 🌟 Features

- **Exact Typography & Styling**: Uses Google Fonts `Playfair Display` (editorial serif heading) and `Plus Jakarta Sans` (crisp modern body sans-serif).
- **Glassmorphism Frosted Card**: Dynamic `backdrop-filter: blur(28px)` with soft lighting, border highlights, and ambient drop shadows.
- **Identical Navigation Bar**: Complete with the custom gradient STACKLY logo glyph, active indicator underline, all 8 navigation items, and styled `LOGIN` & `SIGN UP` buttons.
- **Interactive Functionality**:
  - `START PLANNING` modal inquiry form.
  - `LOGIN` and `SIGN UP` modals with tab switching.
  - Interactive toast notifications.
  - Fully responsive mobile drawer navigation.
- **Ultra High-Definition Background**: 2400×1600 curated photography matching the exact wedding banquet table setting with fairy lights and floral arrangements.
